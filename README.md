# Auth Skin Slim (`auth-skin-slim`)

Плагин для [Azuriom](https://azuriom.com/) без изменения кода ядра и без правок **Skin API**.

## Назначение

1. **Auth API** — в ответ `POST /api/auth/authenticate` добавляется объект `skin` с полем `slim` (`true` — модель Alex / «slim», `false` — Steve / обычная или скин отсутствует).
2. **Кэш в БД** — признак slim сохраняется в таблице `auth_skin_slim` и сбрасывается при смене файла скина (сравнение mtime файла `storage/app/public/skins/{user_id}.png`).
3. **Совместимость с Skin API** (опционально) — в админке плагина можно включить ослабление проверки размеров PNG при загрузке скина/плаща через Skin API (сайт и API), если стандартная валидация отклоняет файл (HD, 64×32, и т.п.).

## Требования

- Azuriom с **включённым Auth API** (`Настройки → Аутентификация → Auth API`).
- PHP с расширением **GD** — для анализа PNG при первом расчёте slim (если нет актуальной записи в БД).
- Плагин **Skin API** не обязателен для поля `skin.slim`, но нужен, если игроки загружают скины через него; настройка «ослабить размеры» действует только при включённом Skin API.

## Установка

1. Скопируйте каталог `auth-skin-slim` в `plugins/`.
2. В панели администратора: **Расширения → Плагины** — установите и **включите** плагин.
3. При включении автоматически выполняется миграция таблицы `auth_skin_slim`.

Если миграция ранее падала с ошибкой внешнего ключа, удалите таблицу `auth_skin_slim` и при необходимости запись в `migrations`, затем снова включите плагин.

## Формат ответа API

После успешной аутентификации к обычному JSON пользователя добавляется:

```json
{
  "id": 1,
  "username": "player",
  "access_token": "...",
  "skin": {
    "slim": true
  }
}
```

Если файла `skins/{id}.png` нет, обычно возвращается `"slim": false`.

## Админка плагина

**Плагины → Auth Skin Slim** (нужно право `admin.plugins`):

| Опция | Описание |
|--------|----------|
| Ослабить проверку размеров изображения при загрузке в Skin API | Временно подменяет настройки размеров только на время запроса загрузки, чтобы `Rule::dimensions` принимал широкий диапазон. Не меняет сохранённые в Skin API значения в БД. |

## База данных

Таблица **`auth_skin_slim`**:

| Поле | Описание |
|------|----------|
| `user_id` | Ссылка на `users.id` (**INT UNSIGNED**, как в Azuriom) |
| `is_slim` | Результат детекта |
| `skin_mtime` | Unix mtime файла скина на момент расчёта |

## Как это устроено технически

- **`MergeSkinSlimIntoAuthApiResponse`** — middleware группы `api`, дописывает `skin` в JSON ответа маршрута `auth.authenticate`.
- **`RelaxSkinApiDimensionsForValidation`** — middleware групп `web` и `api`, при включённой опции и запросах загрузки в Skin API временно расширяет допустимые размеры через `SettingsRepository`.
- **`SkinSlimDetector`** — эвристика по пикселям области рук (как в распространённых клиентах Minecraft).
- **`AuthSkinSlimResolver`** — чтение кэша БД / пересчёт при смене mtime файла.

Код **Skin API** и **ядра Azuriom** не изменяется.
